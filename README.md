# Social-Media-Dopamine-Addiction-Vs-Productivity-Dataset
## 📑 Executive Summary
An end-to-end data analytics project examining the impact of daily screen time and social media behavioral drivers on employee/student productivity, mental well-being, and sleep quality across 300 global participants.
## 💡 Key Business Recommendations
 Establish structured digital wellness guidelines for remote/hybrid teams to limit non-essential notification switches.
 Promote deep-focus time blocks (e.g., 90-minute uninterrupted sprints) to minimize context switching during peak productivity hours.
